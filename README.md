# maui-usecase-demos
This repository contains Syncfusion .NET MAUI use case demos that showcase practical scenarios and sample implementations to help developers understand how to apply Syncfusion MAUI controls in real-world applications.

## Samples

| Sample | Description | Controls Demonstrated |
|---|---|---|
| [StockChart](StockChart/README.md) | Stock portfolio viewer with interactive financial charts, watchlists, trendlines, and range selection | SfCartesianChart, SfPopup, SfTabView, SfComboBox, SfRangeSelector, SfCalendar, SfButton |
| [SfDataGrid](SfDataGrid/) | DataGrid use case sample | SfDataGrid |
| [WeatherForecast](WeatherForecast/) | Weather forecast use case sample | See sample folder |

See each sample's folder for details, prerequisites, and run instructions.
