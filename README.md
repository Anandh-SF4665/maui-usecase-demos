# maui-usecase-demos
This repository contains Syncfusion .NET MAUI use case demos that showcase practical scenarios and sample implementations to help developers understand how to apply Syncfusion MAUI controls in real-world applications.

## Available Samples
| Sample | Description |
|--------|-------------|
| [PatientCare](PatientCare/) | Healthcare management app: dashboard metrics, patient management, appointment scheduling, and care plan tracking |
| [PatientCompanion](PatientCompanion/) | Patient companion app (MediFlow) for tracking medications, appointments, and health records |
| [WeatherForecast](WeatherForecast/) | Weather forecasting app using Syncfusion charts |
| [SfDataGrid](SfDataGrid/) | DataGrid samples for various scenarios |
| [StockChart](StockChart/) | Stock charting with Syncfusion charts |
